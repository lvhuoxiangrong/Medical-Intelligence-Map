本页数据加载流程（示意）

左侧为静态示意，右侧为动态实现：两份 JSON → fetch() → JS 对象 → 渲染函数 → 页面
实现要点：① 两份 JSON 与 HTML 处于同一目录下（子目录「json文件」）；② 用 fetch(相对路径) 读取；③ 拿到 JS 对象后交给各自的渲染函数；④ 浏览器安全限制：file:// 双击打开时 fetch 会被拦截，须用本地服务器访问（见「启动页面.bat」）。
数据口径：以上统计均由页面在加载时从两份 JSON 实时计算，来源与结构见「使用说明.md」。
